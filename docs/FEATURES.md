### Suggest an Edit: supported and unsupported corrections

Supported patch keys are exactly `primaryTitle`, `primaryTitleLanguage`, `releaseStatus`, `publicationYear` (integer1–9999), `publicationLabel` and `originalLanguage`. Text replacements must be nonempty; `und` is a valid language value, not a deletion operation. Unknown keys/null/collection operations are rejected, not queued for later review. Citation label/text and optional informational URL accompany the proposal; citation is not a patch to arbitrary existing source/evidence records and is never fetched.

Not implemented through this workflow: localized PRIMARY/ORIGINAL/ALIAS title rows; authors/other creators and credit roles/order; descriptions/synopses; genre membership; format/country; editions/edition dates/ISBN; Work identifiers/provider links; Work relations/identity merges; cover assets/credits/rights; exact release-event creation/correction/retraction; visibility/UUID/slug changes; clearing existing scalars; collection add/update/remove; amendment/withdrawal/reopening or partial-field approval of an existing suggestion; multi-field browser entry; automatic conflict rebase/merge. A fresh proposal can be submitted at a current published revision, but there is no dedicated existing-proposal resubmission history. Administrator V1 editing or release recording does not mean these corrections are supported by the verified-user suggestion API.
