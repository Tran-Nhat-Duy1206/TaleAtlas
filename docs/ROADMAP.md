### Remaining V2 breadth (not implemented/accepted)

Suggest an Edit currently covers only primary title, primary-title language, release status, publication year/label and original language. The browser submits one field per suggestion; the strict API accepts one or more of those same six fields, never arbitrary Work patches. Missing correction types include localized/alternate titles, creators/credits, descriptions, genres, format/country, editions/identifiers/relations, covers/rights and exact release facts. Clearing a scalar, collection add/update/remove, amendment/withdrawal/reopening or partial-field review of an existing proposal and automatic stale-base rebasing are not supported; creating a fresh proposal at a current revision remains possible. Direct administrator catalog editing and the separate release-recording command are not substitutes for a user suggestion/review workflow. The [recorded-requirement/implementation comparison](<V2_PR_REVIEW.md>) documents all these boundaries and the ordered backlog. No separate detailed original field list was supplied, so maintainers must reconcile any such specification; acceptance is not a certification of full original field-level coverage.

Live external-provider search/retrieval, automatic/scheduled network execution and licensed image/chapter transfer remain conditional future work. Current processing uses only submitted human request input; provider-shaped synthetic JSON decoders make no network calls. Before any live adapter is enabled, verify intended-use/storage/media permissions and provider limits, implement fixed-host bounded transport and demonstrate separate acceptance. A green manual/offline CI run is not a provider permission grant.

Automatic publication is not approved; human authorization and V1 publication controls remain mandatory. No irreversible automatic Work merge, arbitrary URL fetch, chapter storage or unlicensed cover transfer. Hosted Neon/Vercel/SMTP/HTTPS validation is a separate unverified task. Exact milestone state and observations go in `V2_VALIDATION.md`, not revised V0/V1 history.
