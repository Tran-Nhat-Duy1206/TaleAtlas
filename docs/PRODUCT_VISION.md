# Product vision

V0 foundation is implemented with local checks; final validation and production acceptance are separate. TaleAtlas aims to help readers discover stories and keep a private, deliberate reading record, with English and Vietnamese presentation.

V0 builds the trustworthy foundation: account registration, verified email, password recovery, revocable sessions, protected account experience and a coherent accessible shell. It is not a functioning catalog or reader library yet.

Milestone order: V1 global manually curated, source-attributed catalog with local catalog search; V2 remote provider discovery and requests; V3 private reading library/progress/rereads. No catalog, provider, requests or library exists yet. Community discussion, recommendations, imports, analytics and asynchronous refresh require separately approved designs and acceptance gates.

Principles: private by default; stable work identity rather than normalized-title identity; user-local notes/overrides separated from public metadata; clear missing-data states; no invented catalog results or fake statistics. StoryNest informs reading vocabulary; Eiren informs engineering discipline, not Discord functionality.

Success means tested account security and a reliable base before adding product breadth. See FEATURES and ROADMAP for scope; VALIDATION records evidence rather than aspirations.
