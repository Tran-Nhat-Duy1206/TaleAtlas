# Product vision

TaleAtlas aims to help readers discover stories and keep a private, deliberate reading record, with English and Vietnamese presentation. V0 foundation and merged V1 curated catalog are implemented. V2A–D have passed local and actual CI acceptance for the implemented manual/offline requests, human review, limited corrections and public catalog-discovery scope; hosted production acceptance remains separate.

V0 supplies account registration, verified email, password recovery, revocable sessions, protected account experience and a coherent accessible shell. V1 adds the curated global catalog, and V2 adds private requests, conservative review candidates, authorized manual publication/link decisions, six-scalar Suggest an Edit and Recently Added/human-cited exact-day releases. It is still not a private reader library.

Milestone order remains V1 curated catalog → V2 requests/shared ingestion/human review → V3 private reading library/progress/rereads. Live remote-provider discovery is a remaining conditional V2 ambition, not implemented ingestion: current processing normalizes human request input, and provider-shaped synthetic decoders perform no network calls. Providers remain disabled/PENDING until intended-use/storage/media permission and transport/rate controls are separately verified. Broader metadata correction types, private reading library, community discussion, recommendations, imports, analytics and scheduled external refresh require separately approved designs and acceptance gates.

Principles: private by default; stable work identity rather than normalized-title identity; user-local notes/overrides separated from public metadata; clear missing-data states; no invented catalog results or fake statistics. StoryNest informs reading vocabulary; Eiren informs engineering discipline, not Discord functionality.

Success means tested account security and a reliable base before adding product breadth. See FEATURES and ROADMAP for scope; VALIDATION records evidence rather than aspirations.
